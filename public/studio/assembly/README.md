# Work taking shape

`creative-work-taking-shape.webp` is generated Assembl concept art, created on 28 September 2026 for public Studio and the existing Assembl image maker. It is not a photograph of a real location, client work or a Gaussian splat.

The source was generated with the session image-generation tool and optimised to WebP at quality 90. It contains no borrowed logo or depicted client.

Art direction: a wide architectural composition, paper and translucent vellum forming one sculptural ribbon, deep plum recessed walls, paper/chalk surfaces, dusty rose edges, left-hand negative space for real HTML text, low oblique viewpoint, soft light and coherent physical depth. Exclude people, robot imagery, interface screenshots, neon effects, gold and generic glowing orbs.

The public hero applies a small scroll-linked transform with a pause control and reduced-motion still. The separate Studio spatial tour renders the existing owned atelier GLB with its established camera path.
