# Auckland Zoo — brand assets

Uploaded 2026-06-29/07-01 by Kate. Use these for the Auckland Zoo × Keeper ops dashboard, cold-outreach visuals to Kevin Buley + James Chatterton, and the pilot workspace.

## Signature pattern

- `pattern-safari-animals.png` — tileable pattern of giraffe, elephant, lion, monkey, otter, red panda, paw prints, leaves + subtle blue/orange accent dots on off-white. This is the primary Zoo brand watermark. Tile background for dashboard shell, empty states, letterhead, ticket stubs, keeper docs. Ink-line + soft off-white — do not colour-fill the linework itself.

## Editorial animal portraits (studio, warm orange background)

## Usage rules

- Never composite the animal portraits onto anything but the warm orange or an ink/off-white background — the orange is the anchor
- Never colour-fill the safari line pattern — ink line stays ink line
- Portraits work best full-bleed or 3:4 crop, no vignettes, no filters
- Cross-brand with assembl: keep the assembl lockup in Cormorant lowercase on a cream tile in the footer only. Zoo owns 90%+ of every surface
- **Kaumātua-hold on taonga species content**: kiwi, kākāpō, tuatara, tūī — do not generate or use imagery for these without kaumātua sign-off. The uploaded portraits (elephant, giraffe, lions, otter, red panda, squirrel monkey) are safe for immediate use.
