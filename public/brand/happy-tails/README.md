# Happy Tails — brand assets

Uploaded 2026-06-29 by Kate. Use these across the Happy Tails ops dashboard, pitch pack visuals, and marketing surfaces.

## Signature patterns (tileable, black line on warm white)

- `pattern-tails-and-paws.png` — the primary Happy Tails signature. Dachshund silhouettes + wagging tails + paw prints + bones + hearts. Use as: dashboard hero background, page footers, invoice paper, envelope liner.
- `pattern-dogs-mixed.png` — busier variant, adds dalmatian, husky and other breed silhouettes. Use as: 404 page, empty states, secondary marketing.

Both tile seamlessly. Ink line only — no colour fill.

## Editorial dog photography (studio white, back/tail portraits)

Consistent visual language: back-of-dog studio portraits, pure white background, editorial pose, dignified without being cute-slop. All safe to use as hero imagery or supporting photography.

- `franklin-black-longhair-rear.png` — long-haired black-and-tan dachshund, back paws + tail. **This is Franklin's stand-in** (Kate's dog, the Happy Tails brand anchor). Use as the primary hero portrait on the dashboard.
- `dog-tan-play-stance.png` — tan mixed breed, playful nose-down pose.
- `dog-dalmatian-leap.png` — dalmatian mid-leap.
- `dog-dalmatian-standing.png` — dalmatian standing tall.
- `dog-corgi-tail.png` — corgi tail up.
- `dog-husky-fluffy-tail.png` — husky, fluffy curled tail.
- `dog-terrier-tan-tail.png` — terrier mid-stride, black-and-tan.
- `dog-poodle-curls.png` — apricot poodle.

## Palette pairing

Editorial photography + line pattern land on:
- Warm white background `#FBF7F1`
- Ink `#1A1918`
- Champagne hairline accent `#BFA37A` (rare, used only for crossover markers with assembl)

## Usage rules

- Never colour-fill the line patterns — they stay ink-on-warm-white
- Photography stays on white studio background; never composite onto colour
- Prefer Franklin's photo (`franklin-black-longhair-rear.png`) as the anchor whenever a single dog needs to represent the brand
- Rotate the other dog photos as breed variety in secondary surfaces (per-dog CRM records, empty states, roster avatars fallback)
