# AL-03 prototype integration
This is the experimental engineering revision for Assembl Living. The source generator, 8 STEP, 8 STL and validation manifest are delivered as the AL-03 downloadable pack in the associated project conversation. This repo contains an engineering status record, not yet those binaries.
**No commercial release:** the connection is a gravity-located desktop peg, not a locking bayonet; the pegboard has no tested wall fixing. Physical print and clearance testing are pending.
