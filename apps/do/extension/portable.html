What travels with me?

Write, Talk and Add open the same first-party workspace using your normal Assembl session. Talk opens microphone consent; it does not start listening. Add opens the image review. Selected text stays a draft until you review it.

Moving the floating DO shares nothing. Point at an area reads only the area you choose; forms and marked private areas are excluded. Use the separate workspace on sites that block embedded workspaces. This companion has no connected retailer cart or cross-device browser pairing.
