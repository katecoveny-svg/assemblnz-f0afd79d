# DO native iOS development

`DoKeyboard/` contains an offline keyboard source foundation with explicit context review. No signed containing app, Xcode build, TestFlight delivery or live cloud keyboard is established. See its README for device setup and remaining authentication work.

`DoNeedsYouWidget/` remains a separate unverified WidgetKit scaffold. The mobile website and home-screen installation are distinct from native iOS extensions. A web widget cannot float over other apps or become the iPhone keyboard.
