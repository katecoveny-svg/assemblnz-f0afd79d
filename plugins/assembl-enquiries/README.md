# assembl enquiries

Private pilot: every output is staged for human sign-off. This plugin can prepare an enquiry reply and read its status and evidence. It cannot approve or send, lodge, file or submit anything. No financial, legal or regulated advice.

Hosted endpoint: `https://www.assembl.co.nz/api/mcp`. Sign in on `/do/enquiries`, enable plugin access, then connect through the existing Supabase OAuth flow. Human approval happens on Assembl.

See `../../docs/DO-ENQUIRIES-RUNBOOK.md` for registration, revocation, testing and deployment. This package is prepared for testing; it is not a claim of public-directory publication.

Uses the current portable Agent Plugins manifest. The historical `CANON-plugin-architecture-2026-05-08.md` referenced by the scoped guide was not present in the checkout; the root operating contract, existing MCP permissions and current official packaging documentation govern this implementation.
