# Assembl copy review

Use for public website copy and agent-generated pursuits/pitches. Read docs/assembl-copy-standard.md first. This is an editing workflow, not a guarantee that prose has no detectable machine origin.

1. Identify the reader, useful task, evidence and next action.
2. Cut sentences that only describe a mood. Remove quiet/quietly, seamless, unlock, unleash, revolutionary, game-changing, cutting-edge, world-class, ecosystem and synergy unless quoting a source with a clear reason.
3. Replace vague promises with the named output: opportunity brief, source record, draft response, demonstrator, pitch deck.
4. Use New Zealand English. Prefer a full stop to an em dash. Vary sentence length instead of repeating three-part slogans.
5. Preserve important truth: proposal versus fact, source date, missing knowledge, sign-in requirement, provider consent, human approval, unavailable action. Never edit away a limitation to improve conversion.
6. Do not invent demand, budgets, urgency, endorsements, measurable results, testimonials or customer logos.
7. Read aloud. Remove repeated product definitions and template headings. Make the primary action obvious.
8. Review generated work as well as fixed copy. A keyword guard catches banned phrases; only editorial review catches empty or misleading writing.

Examples: 'Three quiet steps beside the work.' → 'Choose the task. Check the context. Review the result.' 'Unlock opportunities.' → 'Find one opportunity worth pursuing.'
