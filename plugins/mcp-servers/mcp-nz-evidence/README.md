# Unpublished NZ specialist MCP candidates

SDK2 factory registers four freight tools or three redacted RFI tools. StdIO packages are real local tools; `src/http.ts` is a separate **unmounted** streamable HTTP factory. Nothing mounts it in Next.js, changes `/api/mcp`, broadens Supabase access, registers clients or activates production.

Build packages: Node24, frozen repository dependencies, `node scripts/build-nz-plugin-candidates.mjs`. No plugin-directory install is needed. Do not run older repository-wide plugin deployment workflows. Dedicated focused CI supplements the existing checks.

Public tools require no OAuth because they process selected non-identifying facts and public Customs references. No generic dispatcher, file path/URL argument, model, credential access, database, storage, billing, external contact or submission capability is present. No request-body logs in the implementation; actual host/access-log retention is a launch gate. Text redaction checks are intentionally incomplete.

Public Customs downloads are fixed, credential-free, redirect-denied and byte/deadline bounded. Compressed tariff≤8MiB, expanded archive≤96MiB, details≤32MiB. Only expected regular tar members; no extraction to disk. Windows-1252 details, explicit producer timezone and actual dated rows. One process memo indexes the public snapshot; one-hour tariff download cache,24-hour FX cache, single-flight≤2 loads. Details parse is synchronous with a finite expanded bound; measured inspected snapshot indexing approximately380ms locally. CPU/memory/load tests on selected production hosting are mandatory before deployment; do not advertise an unmeasured hosting SLA. Old or conflicting sources return explicit states, no fixture fallback.

Tariff effective dates apply to exact supplied items only. A partial-day boundary or overlapping rows is ambiguous. One inspected reversed validity record is quarantined by code; its count is surfaced. No rate-group, concessions or classification inference. FX before2020 is unsupported because old period semantics differ; modern periods must end Sunday and never fill gaps between published fortnights. Rates stay decimal strings, foreign currency per NZD. NZD1.00 is explicitly identity, not a downloaded rate.

HTTP factory has1MiB body cap,10-second handler/body deadline, strict endpoint/origin/content type,4 concurrent requests and60 requests/minute **per process**. These are engineering controls; distributed quotas/DDoS/egress and platform logs still need reviewed hosting. Streamable HTTP legacy and current SDK eras are handled by the pinned SDK. Production HTTPS origin/path and platform routing must be tested rather than invented in manifest.

The earlier authenticated NZBN/private-fixture resource remains closed; no public candidate uses the founder-only enquiry service or its insufficient generic membership JWT adapter. Any future private adapter must validate issuer/resource audience, approved nonnull client, scopes and owner/tenant on every access, plus consent/rights/retention and durable provenance. No charging rails are reused: prior caps use non-atomic read/upsert and ignored errors. Transactional admission/idempotency/reservation/settlement and price/entitlement review remain prerequisite; no billing products are created.
