# assembl RFI Register

Unpublished development candidate. Coordinate a redacted user-supplied RFI register, compare revisions and export a draft response matrix. No source-document inspection.

Build from the repository with Node24 and `node scripts/build-nz-plugin-candidates.mjs`. Unpack the generated ZIP; its `mcp.json` runs a self-contained Node stdio server without installation or keys. Root plugin.json follows the portable Agent Plugins1.0 schema. No marketplace entry or public approval is implied.

The shared unmounted HTTP factory exists for reviewed hosting; this package declares stdio because no production HTTPS endpoint has been activated. It is not ready for public submission. See docs/services/nz-plugin-candidates.md for exact gates.

No client records, uploads, credentials, standards corpus, storage, model calls, commerce or agency submission. Professional review is required.
