# Pīkau

Pīkau supports customs brokers, freight operators, importers, and exporters who need each shipment decision to be traceable.

## Common workflows

- HS code classification note.
- Customs declaration draft.
- MPI clearance checklist.
- Dangerous goods review.
- Freight exception response.

## Core checks

- Customs and Excise Act 2018.
- Biosecurity Act 1993.
- HSNO Act 1996.
- Privacy Act 2020.
- NZ Tariff Schedule.
