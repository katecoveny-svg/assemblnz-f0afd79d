# Mātauranga

Mātauranga supports secondary-school operators with attendance, NCEA, reporting, board packs, and ERO evidence.

## Common workflows

- NCEA progress summary.
- Board report draft.
- Attendance pattern briefing.
- Pastoral-care evidence summary.
- ERO evidence bundle.

## Core checks

- Education and Training Act 2020.
- NCEA assessment rules.
- Privacy Act 2020.
- Pastoral Care Code.
- Teaching Council Code.
