# Integrations

assembl works best when the fleet can read the same operating context your team already uses. Start with the minimum set needed for the kete.

## Core connections

- Stripe confirms the Industry Pack subscription.
- Xero supplies invoice, payment, and customer context.
- Google Workspace supplies calendar and email context.
- Industry systems can be added through tenant tool connections.

## Connection rules

- Keep least-privilege scopes.
- Use one tenant per business operator group.
- Disconnect tools when the business no longer needs them.
- Review generated drafts before sending.

## Troubleshooting

If a connection looks stale, reconnect it from onboarding or tenant settings, then rerun the next briefing.
