# Jules bootstrap for assembl

`.Jules/` contains Jules-specific learnings only. It is **not** a separate company-memory system.

Before substantial work, Jules should read:

1. `START_HERE.md`
2. `AGENTS.md`
3. `config/context-manifest.json`
4. `docs/context/CURRENT.md`
5. `docs/context/README.md`
6. only the task-specific canonical docs + relevant code/tests

`palette.md` contains historical interaction/accessibility learnings. Use those as implementation guidance where still applicable, but they do not override current brand, product, architecture or task canon.

For visual/copy work, `docs/assembl-brand-system.md` and `docs/assembl-copy-standard.md` win over old nearby implementation.

Run `pnpm context:check` when context or brand drift is suspected.

**One source of truth, many adapters.**
