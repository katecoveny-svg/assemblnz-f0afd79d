# private assembl Creative Studio

creative material. They are deliberately stored outside `public/` and are not
served by assembl.co.nz.

Open `assembl-creative-studio.html` locally for the full internal Studio.
Open `assembl-caption-studio.html` locally for the standalone caption tool.
