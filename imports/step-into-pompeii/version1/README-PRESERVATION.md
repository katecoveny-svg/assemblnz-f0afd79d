## Current assessment

An authored Three.js 0.180 educational reconstruction with four places, six evidence stops, three required clues, three knowledge checks, a reflection notebook and export. It is not a Gaussian splat, measured archaeological model or synchronized digital twin. Written evidence distinguishes documented finds from inference and links official archaeological sources. Source fact-checking and specialist/teacher/curriculum review are not completed by this preservation task.

Fresh owner-Chrome QA on 26 October confirms actual WebGL geometry renders: aerial neighbourhood, street-level travel, bakery interior and aerial roof cutaway. At 375 x 812 the scene and investigation panel render and document scrollWidth equals 375 (no horizontal overflow). First clue collection updated field notes from 0 to 1. The owner editing toolbar can overlap mobile drawer/navigation actions; hiding its toolbar restores access. No editor prompt was submitted.

Limitations: this was desktop Chrome responsive emulation, not a physical phone or FPS/load benchmark. All quiz/reflection/export paths were not rerun; the original README records earlier functional tests separately. No audio, uploads, external account actions or curriculum integration tested. Rendering quality is stylized and illustrative. Mobile scene controls occupy substantial space; evaluate on touch hardware before classroom release.

Original README retains the earlier WebGL-unverified report as historical source; the fresh rendered observations above supersede that limitation only for the tested Chrome environment. No application source was modified.
