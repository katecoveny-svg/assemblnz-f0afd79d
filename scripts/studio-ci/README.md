# Private Studio hosted CI proof (synthetic only)

This directory is test code. It is never a provider, owner authentication adapter, account storage implementation or product entry. The production owner page/API/session/SQL files remain unchanged.

The existing `public-pursuit-review.yml` workflow now includes Studio source/script PR paths and a private synthetic test step. Hosted CI generates one marked component copy beside the original (so its relative imports/styles stay exact) and a temporary `/studio-ci-fixture` page. The copy differs only by its transport import plus a generated-file warning. `prepare.mjs` requires CI/GITHUB_ACTIONS, refuses existing output, checks the exact transport import, and supports non-writing `--check`. No generated route/component is committed. The one hosted Next build includes the CI-only entry; this output is never a deploy artifact and must not be deployed. Only logs, screenshots, synthetic backups/downloads and assertions are uploaded. Cleanup removes the generated source files even on failure; the hosted runner discards compiled output.

The browser script uses the actual Next-rendered component and its real CSS. Synthetic records/dispatches live in that browser context's sessionStorage. All nonlocal requests and native API requests in fixture contexts are blocked and recorded. A fixture-context navigation interception handles the component's owner-shaped route after save without claiming owner access. A separate context with no such interception verifies actual `/studio/workspace` and owner API GET/valid POST return 404 without a session. This proves closed unconfigured CI routes only; it cannot prove real owner login, RLS, account persistence, production backend stable-create behavior or provider output.

No local build/install/server was run to prepare these scripts. Local syntax, transport tests, targeted TypeScript and lint are verification of test source only. Hosted browser assertions must run before any browser pass is claimed. Independent source review and reconciliation with latest accepted main precede push/dispatch. No owner activation, production SQL/flags/grants/secrets/spend or outreach is authorized.
