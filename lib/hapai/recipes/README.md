# hapai project recipes

The live recipe pages are rendered from `lib/hapai/project-recommender.ts` so
the project picker, result cards, and one-page recipe routes share one source of
truth.

Each recipe includes:

- tools required
- prompt to copy
- estimated build hours
- estimated hours/week saved
- common failure modes

ROI uses the locked assumption of NZ$80/hour blended professional time.
