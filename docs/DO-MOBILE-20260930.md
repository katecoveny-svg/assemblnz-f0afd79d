## Implementation

- Extends the existing DO home and focus workspace with original editorial artwork, rounded framing and restrained reduced-motion-aware interaction. Existing 3D atelier remains available; no extra autoplay video or new rendering dependency.
- Extends the shared website/extension companion with visual-viewport clamping for phone software keyboards, safe-area spacing, touch-sized controls, readable 16px context fields and a reset-position button. Regenerates the exact extension source and downloadable ZIP.
- Context remains explicit: pick/tap or selection → local review → handoff → provider consent. Movement never captures content. Only positions persist. Mobile web remains scoped to the page; it cannot float across all iPhone apps or install a keyboard.
- Replaces unsafe iOS keyboard scaffold (private host inspection, implicit clipboard fallback and fire-and-forget call to an obsolete endpoint) with an offline UIKit foundation. Explicitly requested nearby text can be reviewed and inserted; ordinary typing and a keyboard-switch button are provided. No network access, clipboard access, cloud preparation or fabricated completion. Development only, not an installable release.

Remaining work: signed containing app, authenticated native preparation bridge, explicit provider consent, full text review/editing, Xcode build, physical-device accessibility/keyboard-height/selection tests and distribution.
