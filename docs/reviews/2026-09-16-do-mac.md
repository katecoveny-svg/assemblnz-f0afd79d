# DO Mac development installer — 16 September 2026

## Delivered

- Reusable disk-image packaging with DO.app, an Applications shortcut and installation notes.
- Current shared D artwork for the app, menu bar and rounded floating widget; removed the old star and independent Swift logo drawing.
- Apple-silicon build with macOS 13 deployment target, version 0.3.0.
- Temporary local staging avoids synced-folder metadata invalidating the signature. Security metadata is preserved.

## Verified

- Swift compilation, shell syntax and whitespace checks passed.
- Strict ad-hoc signature verification passed both before packaging and from the read-only mounted final disk image.
- Disk-image checksum passed. Binary load command reports minimum macOS 13.0; this is not a claim of runtime testing on macOS 13.
- Final app launched from the mounted image. The rounded D was visually inspected and clicking it opened the hosted DO workspace.
- No Accessibility, microphone or screen-recording permission was granted; no user content was captured or sent.

## Still open

- Developer ID signing, Apple notarisation and a public update/distribution route.
- Intel/universal build and testing on older macOS releases.
- Menu-bar interaction, login-item registration, shutdown/restart persistence and drag-position verification. The automated drag attempt opened the workspace instead, so it did not establish correct drag behaviour.
- Hosted workspace still presents legacy assembly controls and the network trial limit; useful task execution and sign-in were not verified in the native shell.
- Target-app label can show a background system app. Filter those out in the next native interaction pass.

The installer is a development artifact, not a public-ready release. Nothing was installed into Applications or published.
