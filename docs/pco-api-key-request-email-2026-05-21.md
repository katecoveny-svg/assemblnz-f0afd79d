# PCO API Key Request Email

To: contact@pco.govt.nz

Subject: Request for New Zealand Legislation API access for authorised legislative retrieval

Kia ora PCO team,

I am writing to request access to the New Zealand Legislation API for assembl, a New Zealand-built software platform that supports organisations with regulatory, compliance, and operational drafting.

assembl uses review-first agent workflows: outputs are prepared as drafts only, and must be reviewed by a named human before being relied on or used externally. We are seeking API access so that these workflows can be grounded in current, authoritative New Zealand legislation from legislation.govt.nz, rather than relying on static summaries or manually maintained copies.

Our intended use of the API is to:

- search for and retrieve current New Zealand legislation
- identify current and historical versions of Acts, Bills, amendment papers, and PCO-published secondary legislation
- retrieve XML, PDF, and HTML source links where available
- monitor legislation changes relevant to compliance workflows
- retain source URLs, version identifiers, and citation metadata
- cite legislation accurately in draft outputs prepared for human review

Initial legislation areas include:

- Privacy Act 2020
- Fair Trading Act 1986
- Consumer Guarantees Act 1993
- Credit Contracts and Consumer Finance Act 2003
- Health and Safety at Work Act 2015
- Building Act 2004 and Building Code-related material
- Food Act 2014
- Customs and Excise Act 2018

We will respect the API terms of use, rate limits, and attribution expectations. Our planned usage is targeted retrieval and scheduled change monitoring, not unrestricted bulk replication. We will cache appropriately, preserve links back to legislation.govt.nz, and ensure users can identify the legislative source behind generated draft material.

Could you please advise the process for obtaining an API key, and whether the PCO has any preferred implementation, attribution, caching, or change-monitoring practices for this type of service?
