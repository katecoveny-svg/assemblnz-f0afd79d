## Small reusable visualisation module proposal

Build **after** faithful workspace/source reconciliation, as one optional experience module inside the existing interactive renderer—not a replacement with pitch cards. Start with a synthetic lounge and a permissioned example floorplan. Let the user select/reposition furniture silhouettes or reviewed cut-outs in a scaled 2D plan, compare two arrangements, see explicit missing dimensions and produce a reviewable adviser checklist. An optional illustrative room image can accompany the plan, distinctly labelled as a visualisation, not an accurate fit prediction.

Inputs: actual approved unit floorplan with scale, measured furniture width/depth/height, door openings and access path, user-selected circulation requirements. Separate each measured value from model inference. Do not produce a definitive fit verdict from summed floor area or a generated image. Accessibility requirements need the relevant qualified reviewer; a picture alone cannot establish suitable clearances or usability.

Privacy: synthetic assets first. Personal photos only after explicit consent for the named processing provider/purpose; strip location metadata, avoid faces/identifying details, define retention/deletion and prohibit public reuse. Recipient grant scope includes selected visual media; owner/private input photos are excluded from shared output by default. No automatic generation, new paid provider or personal-photo upload is authorised by this inventory.

Current working proof is **code + no-provider failure behaviour**, not a live model read, current overseas mechanic, commissioned customer programme, measured spatial fit or production accessibility acceptance. The valuable reusable asset is the meaningful photo/annotation/journey interaction and honest human handoff; current technology and provider choices require the root's separate research and bounded implementation review.
