# Native DO iPhone development · 30 September 2026

Kate asked to merge the web pass, then build the app. PR #1416 merged at `009e5e4ac2bf62ee629f217e64aca7233eb6f5b8`; its Vercel production deployment is READY. This separate branch builds native app source and an unsigned simulator verification path. It is not a TestFlight or App Store release.

## Uses and extends

- Uses canonical DO image/mark and the existing web preparation workflow; native Copy & open DO is explicit and does not silently transmit text.
- Extends the offline UIKit keyboard and replaces the fictional WidgetKit approval count with actual local reviewed-draft availability.
- Creates a shared native draft store: explicit save, separate exact-text review before keyboard release, one-hour expiry, revocation check at insertion, complete file protection, backup exclusion and no keyboard writes.
- Creates SwiftUI containing app, local Share Sheet intake, XcodeGen project and macOS-runner simulator build/tests.

## Definition of proof

Project/YAML/plist/assets can be checked here, but Swift/UIKit must be compiled on an Apple runner. The workflow builds all targets, tests review/expiry/revocation/bounds/corrupt input, and captures a simulator image. Its actual run is the evidence, not merely the workflow file. Signing, App Group access on a physical device, keyboard layout/accessibility and native cloud preparation remain separate gates. No account credentials, provider keys, payments or external messages are included.

The current Apple documentation permits keyboard shared-container reads without open access; this build keeps `RequestsOpenAccess=false` and performs only reads in the keyboard. Signed device verification is still necessary. App Group failure remains visible rather than falling back to an unrelated data store.

## Reversal

Revert this isolated native-source change. There are no server schema/API changes. On a device, remove the keyboard in Settings and delete the app to remove its private data once no related extension remains installed.
