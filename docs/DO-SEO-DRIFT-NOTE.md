# Machine-readable positioning drift

Production verification on 16 September 2026 found that the visible homepage had moved to the current `Pursuit → DO → Studio + Factory` story, but the global JSON-LD and `/llms*.txt` source still described assembl primarily as agentic customer journeys, rewarded wait states and the retired Dash sibling brand.

Treat structured data, root metadata and LLM discovery files as product surfaces. When top-level positioning changes, review them alongside homepage copy.

Current company-level description:

> assembl is a New Zealand software and agent platform for finding, doing and showing valuable work. Pursuit finds evidence-backed opportunities. DO is the portable, model-agnostic agent workforce that executes with explicit permissions and evidence. Studio makes the result tangible through demonstrations, creative and commercial proof. A shared Factory carries context, connectors, model routing, approvals, evals and learning underneath the system.

Agentic customer journeys and productive wait states remain reusable primitives/use cases, not the top-level company definition.
