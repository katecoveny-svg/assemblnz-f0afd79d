# Shared public evidence: first review slice

Base: main 50de8fb5f. This patch shares the existing bounded Parliament adapter between Personal text and Gemini voice. It does not enable weather, transport, general news, topical legislation search or the wider RAG corpus.

Personal text retains its explicit official-reference opt-in. A local relevance check excludes ordinary household bills; only the fixed Parliament selector reaches retrieval. The existing exact citation validator remains in force. Voice has a separate source-sharing checkbox that invalidates prior call consent, plus an authenticated, same-origin, rate-limited endpoint accepting only `{topic:"parliament",consent:true}`. No transcript, profile or other specialist context is sent to that endpoint. Tool IDs remain deduplicated, cancelled requests use the existing abort controller, and all tools share the existing eight-call ceiling. Voice allowance, quote, lease, reservation and reconnect code is unchanged.

Results carry checked time, freshness/status, exact official URLs and expiry. Expired evidence and discovery links do not become verified facts. Recent bill records are not topical search or evidence of enactment. In voice, citation use remains model-guided rather than a deterministic post-generation citation check; a paid end-to-end voice evaluation is still required before claiming that spoken answers reliably cite sources.

Validation: 121 tests passed, one opt-in live Parliament test skipped. Scoped ESLint, full TypeScript check (after reusing canvas dependencies) and diff checks passed. Tests cover no-consent/no-fetch, irrelevant selection, private-field rejection, authentication/origin/rate limits, cancellation, unavailable/expired evidence, Personal grounding and existing voice allowance/lease behavior. Local /do/personal compiled and returned 200; signed-out browser could not reach the new call controls. Authenticated desktop/mobile visual review and a consented voice tool-call evaluation remain pending.

Dependency reuse: root and canvas node_modules are local symlinks to the existing installation. Initial build stopped at missing canvas tsup; reuse of the canvas dependency directory resolved that. Production build then failed because Turbopack rejects the external node_modules symlink. No shared dependencies were changed. No merge or deployment performed.
