# assembl Site Visual System Reset

Date: 2026-05-21

## Principle

Core assembl pages must sell the proof layer, not an individual kete. The first impression should be the neutral assembl evidence vessel, motion, light, and reviewed-output system.

## Rules

- Use `heroVessel` and the pounamu assembl vessel for generic assembl surfaces: home, how it works, evidence pack, pricing, agents, HAPAI index.
- Use kete vessel imagery for kete cards and kete pages.
- Do not use Tōro product wordmarks, social cards, or square brand lockups inside core assembl narrative pages.
- Do not use cropped OG cards or static legacy HTML screenshots as major section art.
- Product screenshots belong inside real product frames only when they demonstrate a working surface.
- Tōro is a whānau product. It can keep its own product identity on Tōro-specific routes, but shared visual registries should use the Tōro vessel until a unified product-mark system is designed.

## Immediate Reset

- `/how-it-works` Stage 05 now uses a neutral assembl evidence vessel for Mana sign-off.
- Shared Tōro image registries now point to Tōro vessel imagery instead of the standalone bird lockup.
- The generic `HeroAssembl` image now uses the pounamu home vessel.
