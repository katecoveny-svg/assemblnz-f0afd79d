## DO NOT REPEAT — four mistakes from this session

These cost hours. They are all the same mistake in different clothes: applying
something globally that needed to be judged one page at a time.

1. **The mosaic on the homepage.** A flat tile pattern laid over Kate's
   cinematic three.js scene. It competed with her best work and lost.
   **Reverted.** The homepage does not need the demo system — it already IS
   the standard. Design constitution: for the live site, *refine, never
   redesign*.
2. **The rhythm layer** (`assembl-rhythm.css`). Forced every `h2` on eighteen
   differently-designed pages to 68px `!important` at a 17-character max-width.
   Result: thick, chunky headings breaking into three stacked lines.
   **Removed from the rollout.** The file still exists in `_generator/` but is
   no longer shipped or linked — delete it if you like.
3. **Regex-patching live HTML** (`patch-visionread.mjs`, earlier in the night).
   Caused duplicate sections after footers, dead event listeners and a doubled
   brace. **Superseded** by `roll-system.mjs`, which is idempotent — it strips
   its own previous output before writing, so it can be re-run safely forever.
4. **Verifying by grep instead of in a browser.** Every "it's fixed" that later
   turned out not to be came from this. If a change is visual, it is not done
   until it has been seen rendered.

## WHAT EXISTS NOW

### The system (`research/_generator/`)

| File | What it is |
|---|---|
| `assembl-system.css` | Layout and scale: photographic hero, statement, stage, split, figures. Five rules, the important one being *the interactive moment must be the biggest object on its screen*. |
| `assembl-motion.css` + `assembl-motion.js` | Nine primitives, all data-attributes: `type` (words assemble out of masks), `rise`, `lines`, `wipe`, `count`, `magnet`, `depth`, `m3d="card"` tilt, scrubbed stages. Degrades fully under `prefers-reduced-motion`. |
| `assembl-cloud.js` | The 3D. three.js r144 point cloud that starts dispersed and **resolves into a form**. Materials: `chrome`, `brass`, `ink`, `brand`, `points`. Fourteen forms: grid, ledger, ring, column, house, villa, car, plane, parcel, shield, leaf, basket, tower, wave. Stops rendering off-screen. |
| `assembl-mosaic.js` | The generative brand pattern. Seeded per client (same pattern every load). ~70% negative space. **It assembles and then STOPS** — one tile turns over every few seconds, nothing else. |
| `roll-system.mjs` | Applies all of the above to all 18 demos. **Idempotent.** Re-run after any change to the system files and every page updates at once: `node _generator/roll-system.mjs .` |
| `assembl-rhythm.css` | ⚠️ **The mistake. Not shipped. Do not re-enable without rebuilding it per-page.** |
