How it works

Four steps, and none of them is a guess dressed as a number.

1 · It reads the photos

An agent estimates the room using objects of known size in frame, and it names which ones it used: a door leaf at about 1.98 m, a light switch at 1.0 to 1.2 m, a benchtop at 0.9 m, a brick course at 86 mm.

2 · It builds a real model

The estimate becomes walls, a floor plate and openings in the Pascal schema, which is MIT-licensed and open source. The same pipeline reads a real IFC file exported from Revit or ArchiCAD.

3 · It sizes the MEP

Extract rates come from the Code. Duct diameters come from ordinary practice at about 3 m/s, and the page labels that as practice rather than as a requirement, because it is.

4 · It checks, and it quotes

Net openable area against 5% of the floor. The 6 m span limit. The extract rate for every moisture fixture it can see. Each with the clause verbatim and the arithmetic shown.

assembl — intuitive agentic customer journeys. Built in Aotearoa. This tool is free and unaffiliated with the Ministry of Business, Innovation and Employment. Photographs are sent to the model for the length of one request and are not stored by us.

It is an estimate. Dimensions read from a photograph carry real error, and the tool reports its own confidence rather than hiding it. Building consent authorities grant consents and issue code compliance certificates. Restricted building work requires a Licensed Building Practitioner. Use this to know what to measure, not instead of measuring.
