# The Monetised Wait State — strategy canon (Kate, 28 Jul 2026)

Kate's locked framework (full text in teamroom floor, 28 Jul): the wait state as
assembl's core product surface, monetised through four layers —
1. **Interface as billboard** — the loader's genuine steps made commercially expressive (sponsored steps, skeleton slots, progress-as-narrative).
2. **Conversational wait states** — streaming chat as native sponsored canvas (interstitial reasoning notes, affiliate chain-of-thought, gated deep-dives).
3. **Agentic commerce** — real countdown offers, priority/boost pricing, micro-tasks.
4. **Data as currency** — zero-party polling in the wait.
Plus: RTWT ("real-time wait state trading") as the future trajectory, and an ethics core (never lengthen waits artificially, never blend sponsored with organic undisclosed, ad-free mode as a paid tier).

## assembl brand-fit filter (applied 28 Jul)
**Adopt now** (fits trust-first, matches shipped demos): sponsored-but-genuine steps; the one opt-in question (already shipped); real countdown offers (seat-hold pattern); loyalty accrual (shipped); ad-free premium tier framing; "progress as narrative".

The blueprint's own ethics section supports drawing this line.
