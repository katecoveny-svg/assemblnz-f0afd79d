The useful commercial frame is not “AI chat”. It is what happens between acquisition and funded outcome: application completion, quote understanding, assessable files, clarification, approval, signing and funding. Each state is observable. Each wait can become actionable.

1 · acquirePaid media, SEO/GEO and landing-page optimisation create the visit.
2 · understandThe agent explains the quote and the customer's next step in plain language.
3 · resolveWhen assessment pauses for clarification, the agent finds the exact issue and prepares the response.
4 · fundThe journey records where customers stall, recover, sign and reach funded outcome.
look underneath

start with one wait, not the whole data warehouse.

A pilot can work from a bounded state model: application ID, current stage, customer-approved context, required clarification, quote/contract state and permitted next actions. Deeper integrations come later only where an action genuinely needs them.

Agent can: retrieve, explain, ask, prepare, route, monitor and escalate.
Agent cannot: invent a rate, override policy, make the credit decision or conceal uncertainty.
Human authority: stays where Nectar's policy, compliance and lending controls require it.
Measurement: completion → assessable → clarified → approved → signed → funded.
