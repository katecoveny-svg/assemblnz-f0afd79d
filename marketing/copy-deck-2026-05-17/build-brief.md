# Build Brief — Assembl Site

## Goal

Premium, warm, responsive website for assembl.co.nz — a New Zealand platform
for specialist AI agents that produce human-reviewed evidence packs.

## Core message

**Mahi that earns its proof.**

## Proposition

Assembl helps NZ organisations run operational work through specialist agents.
Outputs are not just automated — they are grounded in NZ context, reviewed by a
named human, and sealed with an evidence pack.

## Visual direction

Warm paper, museum-quiet, Aotearoa-authentic, premium but not corporate cold.
Delicate translucent glass vessels, cream ceramic forms, pounamu green, amber,
violet, teal, brass details, lots of negative space.

## Avoid

Generic SaaS gradients, robot icons, neon AI visuals, dashboard clichés,
stock photos, dark cyber interfaces.

## Tech

- React / Next.js
- Tailwind CSS
- Clean component architecture
- All text rendered as real HTML (not inside generated images)
- Image assets only for vessel art and editorial backgrounds

## Required pages

1. Home
2. Pilot Sprint
3. Kete overview
4. Individual kete page template
5. Pricing
6. About
7. Contact / Book a pilot
8. Evidence pack example page

## Build requirements

- Fully responsive desktop and mobile
- Mobile hero: copy first, CTAs stacked, vessel image below
- Desktop hero: split — copy left, image right
- Sticky header with subtle blur
- Accessible contrast and semantic HTML
- SEO metadata
- Restrained animations: fade, subtle rise, no gimmicks
- Optimised images with alt text
