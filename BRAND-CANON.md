# assembl brand reference

The one authoritative visual canon is [docs/assembl-brand-system.md](docs/assembl-brand-system.md).
Read it before creating any assembl page, product surface, icon, document or image.

- Operational composition and proof: [DESIGN.md](DESIGN.md)
- Public writing: [docs/assembl-copy-standard.md](docs/assembl-copy-standard.md)
- Machine-readable routing: [config/context-manifest.json](config/context-manifest.json)

This file is a pointer, not a competing palette or typography specification.
The former July guide is retained only as [historical reference](docs/archive/brand/brand-canon-20260729.md). Its Jost, serif, navy, gold and orbit-mark directions must not be used for current assembl work.
